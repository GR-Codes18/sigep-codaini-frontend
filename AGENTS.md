# SIGEP CODAINI — Reglas para el agente
- Al iniciar cada sesión, lee completo `docs/SIGEP_Plan_de_Desarrollo_y_Reglas_del_Agente.md`, luego `PROGRESO.md` y `DECISIONES.md`.
- Responde siempre en español.
- No escribas código hasta que yo confirme el plan del paso.
- De `docs/Propuesta_SIGEP_Codaini_v6.md` lee solo las secciones que indique el paso actual, no el archivo entero.
- Lee la metodología y la especificación visual solo cuando el paso lo requiera.
- En Windows usa `npm.cmd` y `npx.cmd` en vez de `npm` y `npx`.
- Nunca borres ni sobrescribas `docs/`.
- Nunca trabajes directo en `main` ni en `development`: usa una rama propia.
- Nunca hagas commit ni push sin mi confirmación explícita.
- Nunca cambies configuración de Git (`git config`, ni local ni global) sin mi autorización explícita. Si un diff parece raro por finales de línea, avísame y espera.
